# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/riyaz-raz/DepTriage/security/advisories/new

Include the affected version or commit, steps to reproduce, and any relevant impact. Please allow the maintainers a reasonable opportunity to investigate and prepare a fix before publicly disclosing the issue.

## Scope

Security reports are welcome for vulnerabilities in deptriage, including credential handling, unsafe data processing, and behavior that could cause unintended writes to GitHub repositories. The tool is intended to access GitHub read-only.
